# Описание работы программы

Программа Onegin принимает на вход два аргумента: название входного файла и название файла с результатам сортировок. При отсутсвтии аргументов по умолчанию выбираются названия onegin.txt для входного файла и onegin_output.txt для результата.

В основе программы лежит безбуфферное чтение из файла для оптимизации работы, реализованное благодаря open() и read(). Для записи в файл исплоьзуется функция fputs, так как буфферизация в данном случае только ускоряет запись.

 ## Результат

 В начале в файл записыватся отсортированный текст из onegin.txt, сравнение происходит стандартным образом слева направо по алфавиту. 
 Далее строчки сортируются с помощью самостоятельно написанного Quick Sort.

 Затем текст сортируется еще раз, только другим способом. Строки сравниваются с конца, таким образом в итоге строки с одинаковыми окончаниями будут стоять рядом. Использовался стандартный qsort из языка С.

## Отладка

При желании можно включить режим отладки, который может использоваться например для обнаружения ошибок в работа quicksort или компараторов.
